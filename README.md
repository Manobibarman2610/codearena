# CodeArena — Smart Online Coding Judge & Practice Platform

An intelligent online coding judge and educational practice platform designed for computer science students and faculty. Write solutions across multiple languages (C, C++, Java, Python, JavaScript), get instant sandboxed evaluation, and receive real-time AI code diagnostics.

## 🚀 Features

- **Multi-Language Sandbox:** Isolated execution for C, C++, Java, Python 3, and JavaScript (Node.js).
- **150+ Database-Driven Practice Programs:** Organized across basic programs, data structures, and advanced algorithms.
- **AI Coding Mentor & Diagnostics:** Big-O complexity analysis, error explanations, and optimization tips.
- **Student Analytics Dashboard:** Submissions heatmap, accuracy ratings, and topic mastery dossier.
- **Faculty & Academic Suite:** Problem authoring, hidden/sample test cases configuration, and contest management.
- **Global Leaderboard:** Standings, solved counters, and competitive ratings.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern Vanilla CSS3, JavaScript (ES6+), CodeMirror IDE
- **Backend:** Node.js, Express.js, MySQL (mysql2/promise), JWT Authentication, bcryptjs
- **Execution Engine:** Subprocess compilation sandboxes with CPU time caps and memory limits.

## 📦 Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Manobibarman2610/codearena.git
   cd codearena
   ```

2. **Backend Setup:**
   ```bash
   cd backend
   npm install
   # Configure your MySQL credentials in .env
   npm run seed
   npm run dev
   ```

3. **Frontend:**
   Open `index.html` with Live Server or run Vite dev server.
